Aviso de Privacidad

Gestor de tareas · Proyecto académico UVEG

1. Datos que se recopilan

La aplicación almacena los títulos de las tareas y, cuando corresponde, sus descripciones, estado de cumplimiento y fecha de creación. No solicita nombre, domicilio ni datos bancarios.

2. Finalidad del tratamiento

Los datos se utilizan exclusivamente para registrar, consultar, actualizar y eliminar tareas dentro de la aplicación.

3. Almacenamiento y protección

La información se guarda en una base de datos MySQL/MariaDB. El proyecto incorpora medidas técnicas como validación de entradas, conexión mediante HTTPS en el entorno local y encabezados HTTP de seguridad.

4. Compartición de datos

Este proyecto académico no está diseñado para vender ni compartir los datos de las tareas con terceros.

5. Conservación y eliminación

Las tareas permanecen almacenadas hasta que se eliminan mediante las funciones de la aplicación o se borran de la base de datos.

6. Alcance

Esta aplicación es un proyecto académico de uso local. No debe utilizarse para registrar información personal sensible.
