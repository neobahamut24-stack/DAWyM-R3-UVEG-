Términos y Condiciones

Gestor de tareas · Proyecto académico UVEG

1. Uso permitido

La aplicación está destinada a organizar tareas personales y demostrar conocimientos de desarrollo y despliegue web en un entorno académico.

2. Responsabilidades del usuario

El usuario debe registrar información lícita, evitar contenido ofensivo y abstenerse de introducir datos personales sensibles, contraseñas o información financiera.

3. Disponibilidad

Al tratarse de un proyecto académico, la aplicación puede modificarse, interrumpirse o dejar de estar disponible sin previo aviso.

4. Limitación de responsabilidad

La aplicación se proporciona con fines educativos y sin garantía de disponibilidad continua. Su responsable académico no garantiza que el sistema esté libre de errores ni se hace responsable de la pérdida de información derivada de su uso.

5. Seguridad

Se incorporan medidas técnicas de protección; sin embargo, no se garantiza seguridad absoluta. El entorno local y el certificado autofirmado no equivalen a un servicio público de producción.

6. Cambios

Estos términos pueden actualizarse para fines de mejora, mantenimiento o evaluación académica.
